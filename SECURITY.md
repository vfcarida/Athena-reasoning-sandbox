## Security Philosophy: Defense-in-Depth

Athena Reasoning Sandbox is architected to safely execute autonomous reasoning agent trajectories without exposing host environments or cloud accounts to operational or financial compromise:

1. **Cognitive-Executive Separation (Parallax Principle)**:
   - Untrusted LLM reasoning loops cannot directly execute OS commands or manipulate file systems.
   - All tool invocations must cross the typed `ParallaxToolDispatcher` boundary and pass explicit tool allowlist authorization (`is_authorized(tool_name)`).
2. **FinOps AST Pre-Execution Verification**:
   - Every SQL query generated by an agent is parsed into an Abstract Syntax Tree (AST) via `sqlglot` before submission.
   - Queries omitting partition key pruning (`WHERE dt = ...`), issuing unbounded projections (`SELECT *`), or lacking explicit row `LIMIT`s are rejected deterministically before execution.
3. **Execution Sandbox Isolation**:
   - Arbitrary code execution is gated by the `E2BSandboxEngine`.
   - By default, unisolated execution on the host machine is strictly refused (`refuse_unisolated=True`), preventing unauthorized privilege escalation or command injection.
4. **Idempotency Ledger**:
   - Turn state transitions and side effects are keyed via SHA-256 digests (`compute_idempotency_key`), preventing duplicate state alterations upon failure retries.

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a vulnerability or security issue:

1. **Do NOT file a public issue.**
2. Send an encrypted or confidential disclosure to [vfcarida@gmail.com](mailto:vfcarida@gmail.com).
3. Include:
   - A detailed description of the vulnerability and attack vector.
   - Steps or proof-of-concept scripts to reproduce the issue safely.
   - The affected component (e.g., `AthenaQueryGuard`, `ParallaxToolDispatcher`, `E2BSandboxEngine`).
   - Potential impact or risk assessment.

### Response Timelines

- **Initial Acknowledgement**: Within 48 hours of report receipt.
- **Triage & Impact Assessment**: Within 5 business days.
- **Fix & Disclosure Coordination**: We work with reporters to patch issues prior to public disclosure.
