# Athena Reasoning Sandbox

> **Production-Grade, FinOps-Governed Autonomous Data Lake Agent Framework**

Welcome to the documentation for **Athena Reasoning Sandbox**. Athena is an open-source framework designed to evaluate, govern, and execute autonomous AI agentic workflows against big data analytical engines (AWS Athena, Trino, and local DuckDB).

---

## 🏛️ Core Principles

1. **Cognitive-Executive Separation (The Parallax Principle)**:
   The cognitive layer (LLM reasoning loop) operates within an isolated sandbox and cannot directly invoke OS, network, or file system resources. All execution actions must cross the typed **Parallax boundary** (`ParallaxToolDispatcher`) to the **Executive Engine Process**.

2. **FinOps AST Query Governance**:
   Zero unpartitioned query escapes. SQL queries generated by LLM reasoning agents undergo compile-time Abstract Syntax Tree (AST) validation via `sqlglot` (`AthenaQueryGuard`) to enforce partition filters (`WHERE dt = '...'`), explicit column projections (prohibiting `SELECT *`), and result limits before any compute is spent.

3. **Multi-Turn Adaptive Reflection**:
   When a query violates data lake governance or partition policies, the `AutonomousDataAgent` captures the AST error message, appends a `<think>` reflection thought, repairs the SQL query (adding partition clauses, projecting explicit columns, appending limits), and re-executes.

4. **Model Context Protocol (MCP) Standard**:
   Athena provides a native JSON-RPC 2.0 MCP server adapter (`athena-agent --mcp`), allowing external agent environments (Claude Desktop, Cursor, LangChain MCP clients) to leverage Athena's FinOps tools seamlessly over stdio.

5. **Dual-Lane Reproducibility**:
   - **Lane 1 (Lightweight / Offline)**: 100% testable locally without AWS credentials, paid API keys, or GPU hardware, using in-memory DuckDB and deterministic heuristics.
   - **Lane 2 (Heavy / Distributed)**: Full cloud-scale execution with AWS Athena, SageMaker judges, and live E2B micro-sandboxes.
